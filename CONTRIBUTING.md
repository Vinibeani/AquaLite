# Contribuir

1. Compile e rode `./build.ps1 -Test` no Windows.
2. Descreva o comportamento alterado e como foi verificado.
3. Separe testes locais de ensaios em hardware; os testes automáticos não acessam o USB.
4. Não inclua dados pessoais, diagnósticos locais, instaladores, bibliotecas de terceiros ou mídias sem permissão de redistribuição.
5. Preserve leituras ausentes como indisponíveis. Não use dados de demonstração como se fossem sensores ativos.

O código do aplicativo está em `src/AquaLite`; cada pasta representa uma responsabilidade. A formatação usa quatro espaços e arquivos UTF-8.
